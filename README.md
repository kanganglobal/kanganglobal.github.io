# Kangen Wellness Website

A modern, responsive recreation of the Kangen Wellness website (https://www.kangenwellness.com.au/) built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Mobile-first approach with modern CSS Grid and Flexbox
- **Interactive Navigation**: Smooth scrolling and mobile hamburger menu
- **Contact Form**: Functional contact form with validation
- **Product Showcase**: Featured products section with cart functionality
- **Blog Section**: Latest articles and news
- **Modern Animations**: Fade-in effects and smooth transitions

## Sections

1. **Hero Section**: Main banner with Kangen Water introduction
2. **Balance & Purity**: Discover the power section
3. **Ukon Products**: Body and soul nourishment information
4. **Featured Products**: Three main product categories
5. **Contact Form**: Get your first Kangen water machine
6. **Blog**: Latest Kangen water articles
7. **Footer**: Links and contact information

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Inter)

## Setup Instructions

1. Clone or download the project files
2. Add product images to the `images/` directory:
   - `kangen-machine.png` - Main Kangen water machine
   - `ukon-tea.png` - Ukon tea product
   - `organic-turmeric.jpg` - Organic turmeric image
   - `ukon-tea-product.jpg` - Ukon tea product card
   - `ukon-supplements.jpg` - Ukon supplements
   - `air-filter.jpg` - Air filter product
   - `blog-kangen-machines.jpg` - Blog article image
   - `blog-golden-elixir.jpg` - Blog article image

3. Open `index.html` in a web browser or serve through a local server
